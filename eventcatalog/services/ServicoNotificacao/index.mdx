## Visão geral

Worker que consome os eventos e entrega cada e-mail ao webhook do n8n, que envia por SMTP. Não tem API HTTP.

Roda como container na Azure (`miaudota-notificacao`), sem URL pública. Se o n8n estiver fora do ar, a mensagem vai para a fila `.dlq`; depois de resolver, `npm run notificacao:reenviar` devolve as descartadas para a fila de trabalho.
